# AGENTS.md

Instructions for AI coding agents working in this repository.

## Language

- All code (variables, functions, classes, routes, etc.) must be written in **English**.
- All code comments must be written in **English**.
- All file and directory names must be in **English**.
- Conversation with the user may be in Spanish, but nothing that ends up in the repository (code, comments, file/directory names, commit messages) should be.

## Testing

- Development follows **TDD**: for every new feature or fix, write a failing test first, then write the minimum code needed to make it pass.
- Run the test suite before considering a piece of work done.

## Commits

- Commit messages must follow the [Conventional Commits](https://www.conventionalcommits.org/) format (`feat:`, `fix:`, `chore:`, `refactor:`, `test:`, `docs:`, ...).
- Commit messages must be written in **English**.
